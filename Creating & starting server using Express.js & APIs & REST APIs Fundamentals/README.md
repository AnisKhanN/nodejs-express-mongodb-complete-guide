# Creating & Starting Server using Express.js, APIs & REST APIs Fundamentals

This folder contains my practice code and notes for learning how to create and start a server using **Express.js** while understanding the fundamentals of **APIs** and **REST APIs**.

The purpose of this project is to build a strong foundation in backend development before moving on to advanced topics such as databases, authentication, and full-stack applications.

---

## 📚 Topics Covered

### Express.js Fundamentals

- Installing Express.js
- Creating an Express application
- Starting an HTTP server
- Listening on a custom port
- Understanding the request-response cycle

### Routing

- Basic Routes
- GET Requests
- POST Requests
- PUT Requests
- PATCH Requests
- DELETE Requests

### APIs

- What is an API?
- Types of APIs
- How APIs work
- Client-Server Architecture
- JSON Data Exchange

### REST APIs Fundamentals

- REST Principles
- RESTful Endpoints
- HTTP Methods
- URL Parameters
- Query Parameters
- Request Body
- Response Status Codes

### HTTP Status Codes

- 200 OK
- 201 Created
- 400 Bad Request
- 401 Unauthorized
- 403 Forbidden
- 404 Not Found
- 500 Internal Server Error

### Express Features

- Middleware Introduction
- Sending JSON Responses
- Serving Static Files
- Handling Errors
- Route Parameters

---

## 🛠 Technologies Used

- Node.js
- Express.js
- JavaScript (ES6+)
- REST APIs
- JSON
- Postman

---

## 🎯 Learning Objectives

By completing this folder, I aim to:

- Understand how Express.js works.
- Create and run an Express server.
- Build simple REST APIs.
- Learn HTTP methods and status codes.
- Handle client requests and server responses.
- Test APIs using Postman.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Navigate to this folder

```bash
cd "Creating & Starting Server using Express.js & APIs & REST APIs Fundamentals"
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

```bash
node app.js
```

or (if using Nodemon)

```bash
npm run dev
```
