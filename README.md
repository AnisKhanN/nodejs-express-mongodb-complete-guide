# Learn Node.js, Express.js & MongoDB

A personal learning repository for backend development practice with Node.js, Express.js, and MongoDB, including a full SmartClinic SaaS demo project in the [smartclinic by codex](smartclinic%20by%20codex) folder.

## Current Project

The SmartClinic project is a full-stack Next.js + TypeScript + MongoDB application for clinic and pharmacy management. It includes authentication, role-based access, patient and appointment workflows, pharmacy inventory, billing, and reports.

### Run the SmartClinic app

```bash
cd "smartclinic by codex"
npm install
cp .env.example .env.local
npm run dev
```

### Useful commands

```bash
npm run build
npm run seed
```
